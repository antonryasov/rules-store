# RULES. — магазин
Сайт в `docs/`, отдельный Cloudflare Worker в `worker/`, первоначальная база в `database/`. Подробная инструкция — в архиве рядом с папкой репозитория. Пароли и токены никогда не размещайте в репозитории. Исходные товары, цены, остатки и изображения предварительные; перед продажей проверьте их в админке. BIORYX не менять.
Запуск RULES.
